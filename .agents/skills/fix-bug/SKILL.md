# Fix Bug

Link a task ID and capture the failing input/expected behavior before editing. Check whether the problem belongs to our adapter, configuration or upstream. Prefer a small Vati fix when correct; fork upstream only when a source patch is actually necessary. Add a meaningful regression test for behavior, authorization, replay or evidence integrity. Run the affected test and workspace checks; record remaining uncertainty and hand off through finish-task.
